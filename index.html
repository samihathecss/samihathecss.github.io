About Me

I am a Web Application Security Specialist dedicated to identifying and mitigating security risks in modern web applications and WordPress environments.

My work centers on authorized security testing and assessments conducted with proper scope and permission. I focus on evaluating authentication mechanisms, access control implementations, and the integrity of application workflows.

Key areas of focus include:

  • Web Application Security — Assessing OWASP Top 10 vulnerabilities, secure coding practices, and threat modeling.
  • Vulnerability Assessment and Penetration Testing (VAPT) — Authorized, scoped testing to identify and report security gaps.
  • Authorized Penetration Testing — Ethical, permission-based testing with documented reports and remediation guidance.
  • WordPress Security — Securing WordPress installations, plugin audits, malware handling, and migration integrity.
