WP Plugin Risk & Hardening Auditor

Browser Demo — the project's own Python scanner, running locally in your browser

Local processing only. The plugin ZIP or PHP files you select are read inside your own browser using WebAssembly (Pyodide). No plugin source, file name, or scan result is ever uploaded to a server. The only network requests this page makes are to download the public Pyodide and JSZip libraries and the small vendored copy of the auditor's own Python modules.

Safety Limits

  • Maximum upload size25 MB
  • Maximum archive entries2,000
  • Maximum expanded size20 MB
  • Maximum compression ratio100:1
  • Maximum PHP files scanned500
  • Maximum size per PHP file1 MB

An archive that breaks any of these rules is rejected before a single entry is read.

The scan runs the upstream scanner.scan_php_text(), file_scanner.scan_php_file(), scoring.score_findings() and reporting.build_report() implementations. A JSON report with the upstream schema can be downloaded when a scan finishes.

The report is produced in your browser by the upstream report generator and saved straight to your device. It contains rule IDs, severities, file paths, line numbers and findings — never file contents.

Detection Rules

The upstream scanner matches four case-insensitive regular expressions. These are the same rules, with the same severities, that the command-line tool applies.

  • HIGHPHP001 — eval()
  • HIGHPHP002 — unserialize()
  • MEDIUMPHP003 — shell_exec(), exec(), system(), passthru()
  • MEDIUMPHP004 — base64_decode()

⚠️ Limitations

  • The scanner uses regular-expression heuristics. It is not a PHP parser: it cannot understand strings, comments, or obfuscation, so it produces both false positives and false negatives.
  • A match, or a non-zero risk score, does not prove that a vulnerability exists. The risk score only sums severity weights (info 0, low 1, medium 3, high 6, critical 10) to help prioritise review.
  • No uploaded PHP code is ever executed, imported, or served. Files are read as plain text only.
  • The command-line tool scans a directory. This demo accepts a ZIP archive or a set of PHP files instead, because a browser cannot read a local directory; the archive safety check and the per-file scan limits are applied by the demo.
  • Where the command-line tool aborts the whole scan when a file is unreadable, too large, or not valid UTF-8, this demo records that file as skipped and continues with the remaining files.
  • Plugin metadata checks, network behaviour checks and any other analysis outside the four regex rules are not part of this demo.
  • The first load downloads the Pyodide runtime (tens of megabytes) and may take around 30 seconds. Large archives can exceed browser memory limits.

All analysis performed locally in your browser.
